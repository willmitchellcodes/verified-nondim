# ODEbase pilot: scaling symmetries of published polynomial models

Generated by `nondim audit` from https://github.com/yuvraj-singh-math/OscarODEbase (polynomial ODEbase models; ODEbase is by
Lüders, Sturm and Radulescu, built on BioModels). This is a pilot. The numbers are what this
package's solver finds; a second tool (desr) was run only on the small models without
conservation laws, and only a handful of results are checked in Lean (see `docs/ODEBASE.md`).

## Summary

| | |
|---|---|
| models read | 162 |
| not attempted or unreadable | 28 |
| with at least one scaling symmetry (conservation laws respected) | 158 (98%) |
| where scaling can remove at least one parameter | 158 (98%) |
| parameters in total / removable by scaling | 2970 / 553 (19%) |
| models with conservation laws | 84 |
| models where ignoring the conservation laws adds scalings that break them | 4 (2%) |
| models with a scaling symmetry that fit the general Lean certificate format | 126 |
| parameters declared but never used (dropped before the analysis) | 443 |
| small models also given to desr: same scalings and parameter count / different | 25 / 0 |

"Scalings that break a conservation law" are the *spurious* symmetries of Tanburn et al.:
a tool that sees only the differential equations would use them and return a reduction that
is inconsistent with, for example, `x1 + x2 = total`.
